## ⚙️ Publish Settings (frmdnsflust.csproj)

| Setting | Value | Meaning |
|---------|-------|---------|
| `PublishSingleFile` | `true` | One `.exe` file, no DLLs |
| `SelfContained` | `false` | Needs .NET 8 Runtime on PC |
| `RuntimeIdentifier` | `win-x64` | Windows 64-bit only |
| `PublishReadyToRun` | `true` | Faster startup |

> **To publish:** `dotnet publish -c Release -o .\publish`

## 🔄 App Flow

```
Launch
  └─> UAC: require Administrator (app.manifest)
        └─> Form loads
              ├─ lblos: shows "Windows 10 / Windows 11 / ..."
              └─ title: "DNS Flush - HH:mm:ss tt" (updates every 1s)

[Flush DNS] button
  └─> ipconfig /release
  └─> ipconfig /renew
  └─> ipconfig /flushdns
  └─> Auto-trigger ChangeDnsAsync()

[Change DNS] button
  └─> ChangeDnsAsync()

ChangeDnsAsync()
  ├─> MessageBox: "Do you want to change DNS?" [Yes/No]
  │     ├─ No  → log "cancelled" → Application.Exit()
  │     └─ Yes → netsh set 1.1.1.1 (primary)
  │               netsh add 8.8.8.8 (secondary)
  │               ipconfig /flushdns
  │               log "DNS changed successfully"
  └─> Application.Exit()

[Ko-fi PictureBox]
  └─> Opens https://ko-fi.com/thanhnguyen150993 in browser
```
